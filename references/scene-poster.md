# Scene: 海报 / 封面 / 宣传图

> 一张图说清楚一件事，让人想点进来。

---

## 定位

- 用于：活动海报、课程封面、社群宣传图、分享会邀请
- 特点：信息密度低、视觉冲击高、3秒内传达核心信息
- 尺寸：1080×1440（竖版）或 1080×1080（方形）或 1920×1080（横版）

---

## 结构

一张好海报只需要 3 层信息：

```
第1层：我是谁 / 主题是什么（大标题）
第2层：你能得到什么（2-3 个要点或一句话）
第3层：怎么参与 / 品牌标识（CTA 或署名）
```

---

## 排版模式（选一种）

### A. 纵向层叠

```
┌──────────────────┐
│                  │
│  标签/类别       │
│                  │
│  大标题          │
│  （64-96px）     │
│                  │
│  副标题/要点     │
│                  │
│                  │
│  品牌署名        │
└──────────────────┘
```

适用：知识类、课程类、简洁主题

### B. 双栏不对称

```
┌──────────────────┐
│ 文字区  │ 图/装饰│
│ (60%)   │ (40%) │
│         │       │
│ 大标题  │       │
│ 要点    │ [图片]│
│ CTA     │       │
│         │       │
│ 署名    │       │
└──────────────────┘
```

适用：有配图、有IP形象的场景

### C. 居中冲击

```
┌──────────────────┐
│                  │
│                  │
│    大标题居中     │
│    副标题居中     │
│                  │
│    CTA 按钮      │
│                  │
│                  │
└──────────────────┘
```

适用：活动邀请、极简主题

---

## 设计规则

- 标题必须大：≥64px（竖版）/ ≥48px（方形）
- 文字不超过 50 字（少就是多）
- 留白 ≥ 40%
- 配色遵循 brand-dna（陶土橙 ≤ 45% + 宣纸白 + 暖棕）
- 手绘下划线可用于标题强调
- 如有 IP 形象，放在视觉重心位置但不抢标题
- **必须有 1 处"视觉惊喜"** — 大装饰数字、手绘下划线夸张用法、或图片突破边界

---

## 禁忌

- ❌ 信息太多（超过 3 层就太挤了）
- ❌ 字太小（信息流里缩略图看不见）
- ❌ 装饰太多（无印良品 = 少即是多）
- ❌ 多种颜色混用（最多用到 3 色）
- ❌ 通用感过强（要一眼认出是 Moon 明月的）
- ❌ 没有视觉惊喜（平淡无奇）
