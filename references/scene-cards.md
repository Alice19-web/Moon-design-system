# Scene: 小红书图文卡片

> 手机竖屏、字大易读、排版有变化、可一键导出 PNG。

---

## 定位

- 用于：AI教程拆卡、工具分享、读书笔记转图文、知识点卡片
- 平台：小红书（也适用于其他竖屏图文平台）
- 目标：让人想滑到最后一张，然后点收藏

---

## 规格

- 尺寸：**1080 × 1440px**（3:4）
- 最多 **9 张**（建议 5-9 张为佳）
- 浏览器预览缩放：`transform: scale(0.45); transform-origin: top center`
- 导出：html2canvas 本地导出 PNG

---

## 卡片结构

### P1 封面

```
┌────────────────────────────┐
│                            │
│  标签（手绘下划线）          │
│                            │
│  大标题                      │
│  （粗无衬线，64-96px）       │
│                            │
│  三短句 / 副标题             │
│                            │
│  CTA / 引导语               │
│                            │
│  ┌──────────────────┐      │
│  │ Dr. Moon 署名块   │      │
│  └──────────────────┘      │
└────────────────────────────┘
```

- **底色**：陶土橙 `#bc4528` 满底 + 宣纸白文字
- **或**：宣纸白底 + 陶土橙标题
- 标签示例：「0代码基础」「AI效率」「工具分享」

### P2-P8 内容页

每张**必须**使用不同的排版手法（从以下选取）：

1. **大编号 + 标题 + 说明** — 步骤/流程
2. **深色面板** — 代码展示/重点强调（暖深棕底）
3. **对比栏** — Before/After、Do/Don't
4. **引用金句** — 大引号 + 居中文字
5. **图标 + 文字横排** — 要点列表
6. **截图 + 标注** — 操作演示
7. **卡片网格** — 2-4 个小卡片并排
8. **时间线/流程线** — 纵向步骤连接
9. **书卡** — 读书笔记/知识卡片（新增）
10. **聊天气泡** — 对话式教程（新增）

### 视觉惊喜要求（新增）

> **每组卡片中，必须有 1 张"视觉惊喜"卡片。**

可选形式：
- 封面使用**非常规排版**（如大装饰数字占半屏、图片突破边界）
- 中间某张使用**深色面板**（暖深棕底 + 宣纸白文字，打破奶白底节奏）
- 某张使用**手绘下划线夸张用法**（标题下方手绘线加粗加长）
- 某张使用**图片溢出容器**（截图突破卡片边界 20-40px）

**限制**：
- 1 组卡片中不超过 1 张惊喜卡（多了花哨）
- 不能没有（否则整组平淡）
- 位置：建议在 P3-P5（打破前两张的阅读预期）

### 末页（可选）

- 总结 2-3 个要点
- 品牌署名：圆形头像 + 「MOON · 明月」
- 引导语："觉得有用？一键四连 ❤️"

## 字号规范（1080×1440 画面内）

| 元素 | 字号范围 |
|------|----------|
| 封面大标题 | 64-96px |
| 页面标题 | 44-56px |
| 正文/列表项 | 34-40px |
| 辅助说明 | 26-30px |
| 标签/badge | 22-26px |
| 代码 | 28-32px (等宽) |

**核心**：手机上看清楚。标题 ≥44px，正文 ≥34px。

## 排版手法详解

### 1. 大编号步骤

```
┌──────────────────────────┐
│                          │
│  01                      │ ← 大号 Arial Unicode，标准字重，陶土橙
│  ───                     │ ← 陶土橙短线
│  步骤标题                 │ ← 粗无衬线 48px
│                          │
│  说明文字两三行。         │ ← 正文 36px，暖棕色
│  保持简洁明了。           │
│                          │
│  MOON · 明月             │ ← 品牌角标，右下
└──────────────────────────┘
```

### 2. 深色面板

```
┌──────────────────────────┐
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │ ← 暖深棕 #3D342F 底
│                          │
│  标题（宣纸白文字）       │
│                          │
│  ┌────────────────────┐  │
│  │ 代码/重点内容       │  │ ← 更深一层的底色框
│  │ font: Fira Code     │  │
│  └────────────────────┘  │
│                          │
│  💡 提示文字             │ ← 浅陶土色
└──────────────────────────┘
```

### 3. 引用金句

```
┌──────────────────────────┐
│                          │
│         "                │ ← 超大引号，陶土橙 120px
│                          │
│    金句内容居中排列        │ ← 44px，暖棕色
│    保持一到两行            │
│                          │
│         —— 出处           │ ← 灰石色，小字
│                          │
│  ─── ─── ─── ─── ───    │ ← 装饰虚线
└──────────────────────────┘
```

### 4. 书卡（新增）

```
┌──────────────────────────┐
│  ▓ 读书笔记              │ ← 陶土橙标签
│                          │
│  《设计心理学》            │ ← 44px 标题
│                          │
│  好的设计是 invisible     │ ← 36px 摘录
│  的，用户甚至不会注意到   │
│  它的存在。               │
│                          │
│  ─── 唐纳德·诺曼          │ ← 灰石色作者
└──────────────────────────┘
```

### 5. 聊天气泡（新增）

```
┌──────────────────────────┐
│  🧑‍🎨 我想做一个页面...   │ ←  sender 气泡
│                          │
│       🤖 没问题！         │ ← receiver 气泡
│       你只需要描述...     │
│                          │
│  💡 对话式教程更适合      │ ← 提示条
│     新手理解              │
└──────────────────────────┘
```

## 做完自查

- [ ] 每页字号适配手机阅读（标题≥44px，正文≥34px）
- [ ] 有没有使用 HTML 默认样式组件（竖线列表、默认blockquote）
- [ ] 每页是否撑满画面（内容占满，但有呼吸感）
- [ ] 连续 3 页是否有重复的 layout（不允许）
- [ ] 陶土橙使用比例合理（不超过 45%）
- [ ] 品牌署名正确（圆形头像 + 「MOON · 明月」）
- [ ] 总张数 ≤ 9
- [ ] 封面够吸引人（3秒内让人想往下滑）
- [ ] **有 1 张"视觉惊喜"卡片**（深色面板/大装饰数字/图片溢出）
- [ ] **截图发朋友圈不会被说"又是模板"**
