# MOON明月 Design System

> 给 AI 看的个人品牌设计系统。让AI帮你做出风格一致、品质稳定的设计。

---

## 这是什么

一套 Markdown 规范文件 + HTML 模板，定义了 MOON明月 品牌的所有视觉规则。

当你让 Cola 帮你做网页、图文卡片、海报时，AI会先读这些文件，然后按规范输出——保证每次做出来的东西都"像一个人做的"。

## 怎么用

1. 把这个文件夹放到 AI 的 skill 目录（`~/resources/skills/moon-design-system/`）
2. 当你说"帮我做个教程页面" / "做个小红书图文" / "做个海报"时，AI 会自动触发
3. AI 会按 7 步工作流执行：澄清→读规范→选模板→选布局→选组件→自检→交付

## 核心理念

- **约束 = 品质** — 限制选择，保证每次输出都好看
- **活人感** — 手绘元素、暖色调、不完美的温度
- **无印良品** — 克制、留白、少即是多
- **内容为王** — 设计服务于知识传递
- **视觉惊喜** — 每个页面必须有 1 处让人"眼前一亮"的元素，但不能多

## 品牌速览

- **主色**：陶土橙 `#bc4528`（≤ 45%）
- **背景**：宣纸白 `#F4F1ED`（40-50%）
- **正文**：暖棕 `#5D4E47`（15-20%）
- **辅助色**：浅陶土+米灰+浅底+深暖棕+灰石（合计 ≤ 15%）
- **字体**：无衬线粗标题 + 无衬线正文
- **场景**：网页 > 小红书图文 > 海报 > 无限画布

## 怎么改成你的品牌（Fork 指南）

1. **改 `brand-dna.md`** — 替换颜色、字体、气质关键词、IP 形象描述
2. **改 `assets/avatar.jpg`** — 换成你的头像
3. **组件库可以先不动** — 等积累了自己的偏好再替换或新增
4. **调整禁忌清单** — 根据你的审美增减禁忌项
5. **把整个文件夹放到 AI 能读到的地方** — Kimi 上下文 / Cola Skill 目录 / Claude Project 等
6. **告诉 AI**："做设计之前先读 SKILL.md"

> 核心不是这些文件本身，是 **你的审美判断力**。文件只是把你的判断写成了 AI 能执行的规则。
